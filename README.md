# 静心计时 · Meditation Timer

一个极简的冥想计时器（微信小程序版）：选时长、点开始、闭眼坐，磬声会告诉你时间到了。

<p align="center"><i>开始一磬 · 间隔轻磬 · 结束三磬</i></p>

## 功能

- **时长预设**：5 / 10 / 15 / 20 / 30 / 45 / 60 分钟
- **结构化坐禅**：正坐 → 经行 → 正坐（15/5/15 或 20/5/20），阶段交界双磬提醒换姿势
- **呼吸引导**：独立页面，4-7-8 安神 / 盒式 / 平衡 / 放松四种节奏，圆环随呼吸缩放、木鱼提示切换
- **修行记录**：每次练习自动记账——今日时长、连续天数、累计总时长、最近 7 天，一眼看见积累（只存本地）
- **间隔磬声**：可设每 1 / 3 / 5 / 10 分钟轻敲一声（可关），长坐时心里有数
- **锁屏可响**：使用微信后台音频（`BackgroundAudioManager` + `requiredBackgroundModes` 声明），手机锁屏、切到别的 App，磬声照常响起
- **不漂移**：计时用「结束时刻 − 当前时刻」的绝对时间差计算，切后台被系统节流也不会越走越偏，回到前台立即校准
- **屏幕常亮**：练习中可保持屏幕不熄灭（可关）
- **磬声**：程序合成的铜磬音色（泛音列 + 长衰减），两支音频仅约 34 KB

## 界面

深色、安静：一个进度圆环、剩余时间、几个大按钮。练习开始后设置区自动收起，只剩时间和状态。

## 本地运行

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册小程序账号：在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 点「立即注册 → 小程序」，个人主体免费，完成后在「设置 → 基本设置」里拿到自己的 **AppID**
3. 开发者工具里「导入项目」：选择本仓库目录，AppID 填你自己的
4. 点「预览」扫码，在手机上真机体验（锁屏测磬声请务必用真机，模拟器不准）

## 技术结构

```
├── app.json            # 后台音频声明 requiredBackgroundModes: ["audio"]
├── pages/index/        # 唯一的页面：计时引擎 + 界面
│   ├── index.js        # 坐禅：绝对时间计时、分段、磬声调度
│   └── breathing/      # 呼吸引导页（在 pages/ 下）
├── utils/log.js        # 修行记录与统计（本地存储）
└── assets/             # 合成音频：磬 bowl.mp3 / 轻磬 bowl-soft.mp3 / 木鱼 muyu.mp3
```
